# Bank Management System

A console-based Bank Management System built using Java 24.

## Features

* Create Account
* Deposit Money
* Withdraw Money
* Search Account
* Display All Accounts
* Delete Account
* Update Holder Name
* Check Balance
* Transfer Money
* View Transaction History
* PIN Authentication
* Exception Handling

## Technologies Used

* Java 24
* Eclipse IDE
* Git
* GitHub
* Collections Framework
* Object-Oriented Programming (OOP)

## Project Structure

src/
└── bank/
├── Account.java
├── Bank.java
└── Main.java

## How to Run

1. Clone the repository.
2. Open the project in Eclipse.
3. Run `Main.java`.
4. Use the menu to perform banking operations.
